This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Arcade Vault: an online platform to play games and compete for the highest score. The project follows Spec Driven Design (`/spec` and `/spec-impl` skills, installed via `npx skills@latest add Klerith/fernando-skills`). The codebase is currently the untouched Create Next App scaffold (`app/layout.tsx`, `app/page.tsx`).

## Next.js version warning

This uses Next.js 16.4 / React 19.3, which has breaking changes versus common training data. Per `AGENTS.md`, read the relevant guide under `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`) before writing Next.js code, and heed deprecation notices. `AGENTS.md` is re-generated by `next dev`.

## Architecture notes

- App Router only (`app/`). Path alias `@/*` maps to the repo root.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching` and `experimental.agentFeedback`. `cacheComponents` changes caching/rendering semantics (dynamic data access must be handled explicitly, e.g. under Suspense), so check the docs before fetching data.
- Tailwind CSS v4 is wired through a custom Turbopack rule (`@tailwindcss/turbopack`) in `next.config.ts`, not PostCSS. Theme tokens live in `app/globals.css` (`@theme inline`, light/dark via `prefers-color-scheme`).
- Layouts use the globally generated `LayoutProps<"/">` type (no import needed); expect similar generated route-typed helpers.
- Fonts: Geist / Geist Mono via `next/font/google`, exposed as CSS variables.
